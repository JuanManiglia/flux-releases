# Flux — descargas

**Flux** es un editor de código para Windows construido sobre [Zed](https://github.com/zed-industries/zed):
rápido, en Rust, y capaz de ejecutar extensiones del ecosistema de VS Code (Claude Code, Codex,
GitLens…) **sin tener VS Code instalado**. Trae notebooks de Jupyter y un asistente de IA gratis.

➡️ **Página de descarga: https://flux-landing-three.vercel.app**

O directamente desde [Releases](../../releases/latest): baja `Flux-windows-x64.zip`, descomprímelo
entero y ejecuta `flux.exe`. La guía completa está en `INSTALAR.txt` dentro del zip.
